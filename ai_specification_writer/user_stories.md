# User Stories – Smart Budget Manager

### User Story 1
As a user, I want to create an account so that I can securely manage my financial information.

**Acceptance Criteria**:
- User can register with an email and password.
- System validates the entered information.
- User receives confirmation after successful registration.

**Priority**: MVP

### User Story 2
As a user, I want to add my income so that I can track how much money I earn.

**Acceptance Criteria**:
- User can enter an income amount.
- User can add a description and date.
- System updates the total income automatically.

**Priority**: MVP

### User Story 3
As a user, I want to record my expenses so that I can monitor my spending.

**Acceptance Criteria**:
- User can enter an expense amount.
- User can select an expense category.
- System saves the expense and updates the balance.

**Priority**: MVP

### User Story 4
As a user, I want to create monthly budgets so that I can control my spending.

**Acceptance Criteria**:
- User can set a monthly budget limit.
- User can assign a budget to a category.
- System displays the remaining budget.

**Priority**: MVP

### User Story 5
As a user, I want to view a financial dashboard so that I can understand my financial situation.

**Acceptance Criteria**:
- Dashboard displays income, expenses, and balance.
- User can select a reporting period.
- System displays financial information using charts.

**Priority**: High

### User Story 6
As a user, I want to create savings goals so that I can save money for future plans.

**Acceptance Criteria**:
- User can set a savings target.
- User can add money to the savings goal.
- System displays savings progress.

**Priority**: High

### User Story 7
As a user, I want to categorize transactions so that I can understand my spending habits.

**Acceptance Criteria**:
- User can select a category for each transaction.
- System provides predefined categories.
- User can filter transactions by category.

**Priority**: High

### User Story 8
As a user, I want to edit or delete transactions so that I can correct my financial records.

**Acceptance Criteria**:
- User can edit transaction details.
- User can delete a transaction.
- System updates the balance automatically.

**Priority**: Medium

### User Story 9
As a user, I want to generate financial reports so that I can analyze my spending over time.

**Acceptance Criteria**:
- User can select a date range.
- System displays income and expense summaries.
- User can view spending by category.

**Priority**: Medium

### User Story 10
As a user, I want to receive budget notifications so that I can avoid overspending.

**Acceptance Criteria**:
- System monitors spending limits.
- User receives a notification when 80% of the budget is used.
- User receives a notification when the budget is exceeded.

**Priority**: Low
