
# User Stories - Feedback Collection App

## 1. Submit Feedback
As a user, I want to submit feedback through a simple form so that I can share my ideas and suggestions.

## 2. View Feedback
As a team member, I want to view all submitted feedback so that I can understand users' opinions.

## 3. Search Feedback
As a team member, I want to search feedback by keywords so that I can quickly find specific comments.

## 4. Filter Feedback
As a team member, I want to filter feedback by category and status so that I can organize requests easily.

## 5. Export Feedback
As a team member, I want to export feedback as a CSV file so that I can analyze the collected data.

## 6. Chat with Team
As a user, I want to communicate through a chat section so that I can discuss my feedback.

## 7. Receive Notifications
As a user, I want to receive confirmation messages after submitting feedback so that I know my action was successful.
