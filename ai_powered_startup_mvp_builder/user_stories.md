
# User Stories

## User Story 1: Submit Feedback
As a user, I want to submit feedback through a form so that I can share my thoughts quickly.

## User Story 2: Enter Contact Information
As a user, I want to provide my name and email optionally so that the team can identify my feedback when necessary.

## User Story 3: Provide a Rating
As a user, I want to rate my experience so that the team can understand my level of satisfaction.

## User Story 4: Select Feedback Category
As a user, I want to select a feedback category so that my feedback can be organized.

## User Story 5: View Submitted Feedback
As a product manager, I want to view submitted feedback in a dashboard so that I can review user opinions in one place.

## User Story 6: Search Feedback
As a product manager, I want to search feedback entries so that I can quickly find specific comments.

## User Story 7: Export Feedback
As a product manager, I want to export feedback as a CSV file so that I can analyze the collected data using other tools.

## User Story 8: View Feedback Details
As a product manager, I want to open individual feedback entries so that I can read the full comments and details.

## User Story 9: Receive Submission Confirmation
As a user, I want to receive a confirmation after submitting feedback so that I know my response was successfully recorded.

## User Story 10: Manage Feedback Capacity
As a product manager, I want the application to limit stored feedback entries to 100 so that the MVP remains simple and manageable.
