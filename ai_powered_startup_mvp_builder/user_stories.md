# User Stories – Real-Time Job Board with Chat-Based Assistance

## User Story 1 – View Job Listings

As a user, I want to view available job listings so that I can find opportunities that match my skills and interests.

**Acceptance Criteria:**

- The user can access the job listings section.
- The application displays available job listings.
- Each listing shows the job title, company, location, and description.
- The user can open a listing to view more details.

**Priority:** MVP

## User Story 2 – Create a Job Listing

As an employer, I want to create a job listing so that I can advertise available positions.

**Acceptance Criteria:**

- The employer can enter a job title, company name, location, and description.
- The employer can submit the job listing.
- The submitted listing appears in the job listings section.
- Required fields must be completed before submission.

**Priority:** MVP

## User Story 3 – Edit and Delete Job Listings

As an employer, I want to edit or delete my job listings so that I can keep job information accurate and up to date.

**Acceptance Criteria:**

- The employer can edit an existing job listing.
- The employer can update job details.
- The employer can delete a job listing.
- The application asks for confirmation before deletion.
- Updated information is displayed correctly.

**Priority:** High

## User Story 4 – Submit a Job Application

As a job seeker, I want to apply for available jobs so that I can express my interest in employment opportunities.

**Acceptance Criteria:**

- The user can select a job listing.
- The user can submit an application with personal information and a message.
- The application is saved successfully.
- A confirmation message appears after submission.
- The user cannot submit an empty application.

**Priority:** MVP

## User Story 5 – Create an Assistance Request

As a user, I want to create an assistance request so that I can ask questions and receive help from the platform.

**Acceptance Criteria:**

- The user can enter a request title.
- The user can describe their problem or question.
- The user can submit the assistance request.
- The submitted request appears in the Requests section.
- A success message appears after submission.

**Priority:** MVP

## User Story 6 – View and Manage Assistance Requests

As a user, I want to view my submitted assistance requests so that I can track their progress and manage my questions.

**Acceptance Criteria:**

- The user can view submitted requests.
- Each request displays its title, description, and submission date.
- The user can open a request to view its details.
- The application displays an appropriate message when no requests are available.

**Priority:** MVP

## User Story 7 – Real-Time Chat

As a user, I want to communicate through a real-time chat interface so that I can exchange messages and receive assistance without refreshing the page.

**Acceptance Criteria:**

- The user can open the Chat section.
- The user can enter and send messages.
- Messages appear in the conversation.
- New messages are displayed in real time.
- The chat interface updates without requiring a page refresh.

**Priority:** MVP

## User Story 8 – Receive AI-Powered Assistance

As a user, I want to ask questions and receive AI-generated responses so that I can get quick guidance and support.

**Acceptance Criteria:**

- The user can enter a question in the chat interface.
- The application sends the question to the AI assistance service.
- The AI generates a relevant response.
- The response is displayed in the chat interface.
- An error message appears if the AI service is unavailable.

**Priority:** High

## User Story 9 – View Chat History

As a user, I want to access previous conversations so that I can review earlier messages and continue discussions.

**Acceptance Criteria:**

- The application stores conversation messages.
- The user can view previous messages.
- Messages are displayed in chronological order.
- The conversation history remains available after refreshing the page.

**Priority:** High

## User Story 10 – Receive Feedback on Actions

As a user, I want to receive confirmation or error messages when performing actions so that I know whether an operation was successful.

**Acceptance Criteria:**

- A success message appears after submitting a job listing or assistance request.
- A confirmation message appears after sending a message.
- An error message appears when an operation fails.
- Validation messages appear when required fields are missing.
- Feedback messages are clear and easy to understand.

**Priority:** MVP
