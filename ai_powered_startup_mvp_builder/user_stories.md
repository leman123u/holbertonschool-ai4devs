
# User Stories - Task Management App

## User Story 1
As a user, I want to create a new task so that I can organize my daily activities.

## User Story 2
As a user, I want to edit my tasks so that I can update task information.

## User Story 3
As a user, I want to delete tasks so that I can remove unnecessary activities.

## User Story 4
As a user, I want to mark tasks as completed so that I can track my progress.

## User Story 5
As a user, I want to set deadlines so that I can manage my time effectively.

## User Story 6
As a user, I want to assign priorities to tasks so that I can focus on important activities.

## User Story 7
As a user, I want to organize tasks into categories so that I can find them easily.

## User Story 8
As a user, I want to search for tasks so that I can quickly find specific activities.

## User Story 9
As a user, I want to filter tasks by status so that I can see pending and completed tasks.

## User Story 10
As a user, I want to view all my tasks in one dashboard so that I can manage my activities easily.
