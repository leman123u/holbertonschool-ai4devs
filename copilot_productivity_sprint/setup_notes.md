## 3. Installation and Configuration

1. Download and install Visual Studio Code.
2. Install Git and verify it using `git --version`.
3. Open VS Code and navigate to the Extensions Marketplace.
4. Install GitHub Copilot and GitHub Copilot Chat.
5. Sign in to GitHub through VS Code.
6. Authorize GitHub Copilot access.
7. Enable inline code suggestions in VS Code settings.
8. Open the Copilot Chat panel and test a coding question.
9. Review AI-generated suggestions before accepting or saving them.

## 4. AI Assistant Configuration

- Enable inline suggestions while typing.
- Use Copilot Chat to ask questions and explain existing code.
- Use AI assistance for code generation, debugging, and refactoring.
- Review generated code manually before using it.
- Never share API keys, passwords, or private credentials in prompts.

## 5. Verification

- Confirm that both Copilot extensions are installed.
- Confirm that GitHub authentication is successful.
- Test inline code completion.
- Test Copilot Chat with a simple coding question.

## 6. Goal

The goal of this setup is to explore how GitHub Copilot, inline completion, and AI chat can improve coding productivity and support a beginner's software development workflow.
